# История изменений


## 2026-07-26

**Релиз v0.5 — интеграция импортёра, консольный интерфейс и улучшения CLI**

- **Добавлен LLMCode_Importer** — новая утилита для распаковки снапшотов кода обратно в файлы. Позволяет восстановить проект из Markdown-экспорта, созданного основным экспортёром.
- **Интеграция в единую точку входа** — импортёр теперь вызывается через основное приложение с помощью флага `--start-input`. Это позволяет использовать один инструмент для экспорта и импорта.
- **Консольный интерфейс импортёра** — реализован интерактивный режим (без аргументов) и CLI-режим (с аргументами). Поддерживаются опции `--output`, `--config`, `--overwrite`/`--no-overwrite`, `--help`.
- **Поддержка конфигурации** — импортёр умеет загружать настройки из `unpacker.settings.json` (путь к снапшоту, выходная папка, перезапись).
- **Улучшенная обработка ошибок** — цветной вывод, валидация путей, понятные сообщения об ошибках в обеих утилитах.
- **Обновлённая структура решения** — проект импортёра добавлен в общее решение (`.sln`) и собирается вместе с остальными проектами одной командой `dotnet build`.
- **Расширенный CLI основного приложения** — добавлен флаг `--start-input`, который передаёт управление импортёру. Теперь пользователи могут работать с обоими инструментами через единый интерфейс.
- **Документация и справка** — обновлены встроенные подсказки (`--help`) для всех режимов работы.


## 2026-07-06
**Релиз v0.4 (Beta) — архитектурный анализ и экспорт для LLM**

- **Архитектурный анализ** — автоматическое определение слоёв (Domain, Application, Infrastructure, UI, Tests) и архитектурного стиля проекта (Clean Architecture, MVC, Web App, Hybrid и др.).
- **Семантическое описание архитектуры** — генерация текстового описания проекта на естественном языке для быстрого понимания структуры LLM и экспертами.
- **Метрики качества кода** — сбор статистики: SLOC, количество классов и методов, средняя и максимальная длина метода, индекс поддерживаемости, разбивка по слоям.
- **Аннотации ключевых компонентов** — автоматическое извлечение XML-комментариев (C#) и docstring (Python) или генерация описания роли для каждого важного файла/класса.
- **Анализ зависимостей между слоями** — выявление нарушений Clean Architecture (например, UI → Infrastructure) с выводом предупреждений в отчёт.
- **Интеграционная диаграмма** — визуализация связей между Backend и Frontend в гибридных проектах (вызовы IJSRuntime, fetch/axios запросы к API) в формате Mermaid.
- **Диаграмма слоёв** — Mermaid-граф, показывающий иерархию и количество файлов в каждом архитектурном слое.
- **Новый формат экспорта: Markdown + JSON** — единый `.md` файл, содержащий читаемый отчёт и структурированный JSON-блок в конце для машинной обработки.
- **Гибридный режим с выбором языков** — поддержка проектов, сочетающих разные языки (например, C# + JavaScript). Пользователь может вручную выбрать язык бекенда и фронтенда.
- **Автоопределение языков в гибридных проектах** — детектор определяет список языков, присутствующих в проекте (C#, Python, JavaScript, TypeScript, Java, Go, Ruby, PHP), и автоматически настраивает режим.
- **Ключевые компоненты в отчёте** — выделение наиболее важных файлов (точки входа, крупные файлы, классы с суффиксами Service/Repository/Controller) с указанием их роли.
- **Улучшенная обработка ошибок** — добавлено логирование ошибок во все новые модули (MetricsCollector, AnnotationGenerator, DependencyRuleChecker).
- **Расширенный CLI** — поддержка новых аргументов: `--format=md+json`, `--hybrid`, `--backend=<lang>`, `--frontend=<lang>`.
- **Обновлённое интерактивное меню** — добавлены пункты для выбора гибридного режима, формата Markdown+JSON и отображения архитектурных метрик.
- **Исправлена ошибка в Compact-режиме** — корректная обработка вложенных классов с использованием стека фигурных скобок.

## 2026-06-24
- **Пользовательский конфиг исключений** — теперь вы можете загружать свой JSON-файл с паттернами и папками для исключения через ключ `--exclude-config=путь/к/config.json`. Это позволяет гибко настраивать фильтрацию без изменения кода. Поддерживается как добавление к стандартным исключениям, так и полная их замена (параметр `OverrideDefaults: true`).

- **Исправлены все внутренние ссылки** – навигация по сайту теперь работает корректно.
- **Улучшена загрузка** – все ресурсы подгружаются по абсолютным путям.
- **Обновлена навигация** – добавлен пункт «История изменений» в разделе «О проекте».
- **Дизайн страницы** – адаптирован под общий стиль сайта, поддерживает светлую и тёмную тему.
