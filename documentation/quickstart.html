Быстрый старт

Способ 1. Работа через приложение (ярлык)

Windows

  1. Найдите папку, в которую вы распаковали скачанный архив программы.
  2. Запустите исполняемый файл LLMCodeExporter.CLI.exe двойным кликом.
  3. Просто перенесите (перетащите мышкой) в открывшееся окно программы свою рабочую папку, в которой вы ведёте разработку.

Linux

На Linux нельзя запустить программу двойным кликом, потому что это консольное приложение, которому нужен терминал для ввода/вывода. Запускайте её так:

  1. Откройте терминал.
  2. Перейдите в папку с распакованным архивом (например, cd /путь/к/папке) или просто перетащите исполняемый файл в окно терминала – путь подставится автоматически.
  3. Если файл ещё не имеет прав на выполнение, дайте их: chmod +x LLMCodeExporter.CLI.
  4. Запустите: ./LLMCodeExporter.CLI (или нажмите Enter после перетаскивания).
  5. Далее перетащите свою рабочую папку в открывшееся окно терминала (или введите путь вручную) – программа начнёт интерактивный опрос.

После запуска (вне зависимости от ОС) программа проведёт вас через пошаговый интерактивный опрос: выбор типа проекта, режима экспорта, фильтров, формата и дополнительных оптимизаций.

Способ 2. Запуск через консоль (CLI)

Если вам удобнее работать в терминале — например, для автоматизации, написания скриптов или интеграции в CI/CD — используйте интерфейс командной строки. В CLI-режиме вы можете гибко управлять поведением программы без интерактивного опроса, передавая все настройки через ключи. 

# Пример базового запуска (автоопределение типа, режим Balanced по умолчанию)
LLMCodeExporter.exe "C:\Projects\MyApp"   # Windows
./LLMCodeExporter.CLI "/home/user/Projects/MyApp"   # Linux

# Пример с явным указанием режима и фильтров
LLMCodeExporter.exe "C:\Projects\MyApp" --mode=compact --backend-only

Способ 3. Импортёр – распаковка снапшотов

Начиная с версии v0.5, в состав решения входит LLMCode_Importer – утилита для восстановления файлов из Markdown-экспорта (снапшота), созданного основным экспортёром. Вы можете запустить импортёр как отдельно, так и через основное приложение с ключом --start-input.

4.1. Запуск через основное приложение (рекомендуется)

dotnet run --project src/LLMCodeExporter.CLI -- --start-input "путь/к/снапшоту.md" --output "папка/для/распаковки"

Если не указать --output, файлы будут распакованы в текущую папку. Если не указать --start-input и не передать аргументы, импортёр запустится в интерактивном режиме.

4.2. Запуск напрямую (как отдельная утилита)

dotnet run --project LLMCode_Importer -- "путь/к/снапшоту.md" --output "папка/для/распаковки"

Подробнее об импортёре читайте на отдельной странице Импортёр.

Способ 4. Веб-конфигуратор (графический интерфейс)

Для тех, кто предпочитает визуальный интерфейс, в составе проекта есть веб-конфигуратор (files-web-wiki). Он позволяет:

  • Выбирать режим экспорта, формат, пресеты.
  • Настраивать фильтры включения/исключения.
  • Сохранять до 50 конфигураций в локальном хранилище браузера.
  • Загружать последнюю использованную конфигурацию.
  • Экспортировать историю конфигураций в JSON.
  • Копировать готовую команду для запуска в терминале.

Откройте веб-конфигуратор прямо в браузере или перейдите на страницу описания.
