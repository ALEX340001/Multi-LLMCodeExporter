Импортёр (LLMCode_Importer)

Импортёр – это утилита, которая распаковывает файлы из Markdown-снапшота, созданного основным экспортёром. Она позволяет восстановить проект или отдельные файлы в исходную структуру папок.

Как это работает

Импортёр сканирует Markdown-файл, ищет блоки кода с заголовками вида ## 📄 `путь/к/файлу` и создаёт соответствующие файлы в указанной выходной папке, сохраняя вложенность директорий.

Запуск

Через основное приложение (с ключом --start-input)

dotnet run --project src/LLMCodeExporter.CLI -- --start-input "snapshot.md" --output "./restored"

Напрямую

dotnet run --project LLMCode_Importer -- "snapshot.md" --output "./restored"

Если не указать --output, файлы будут распакованы в текущую папку. Если не указать аргументы, импортёр запустится в интерактивном режиме.

Ключи импортёра

КлючОписание
--output, -o <папка>Выходная папка для распакованных файлов.
--config, -c <файл>Файл конфигурации unpacker.settings.json (по умолчанию ищется в текущей папке).
--overwriteПерезаписывать существующие файлы (по умолчанию).
--no-overwriteНе перезаписывать существующие файлы.
--help, -hПоказать справку.

Файл конфигурации

По умолчанию импортёр ищет файл unpacker.settings.json в текущей папке. Пример содержимого: 

{
    "OutputRoot": "./restored",
    "Overwrite": false,
    "DefaultSnapshotPath": "snapshot.md"
}

Параметры, переданные через командную строку, имеют приоритет над конфигом.

Пример использования

# Распаковать снапшот в папку my_project, перезаписывая файлы
LLMCode_Importer snapshot.md --output ./my_project
