Установка

Windows

  1. Скачайте win-x64.zip из релизов.
  2. Распакуйте архив.
  3. Запустите LLMCodeExporter.CLI.exe.

Linux

  1. Скачайте linux-x64.tar.gz.
  2. Распакуйте: tar -xzf linux-x64.tar.gz
  3. Запустите: ./LLMCodeExporter.CLI

Сборка из исходников

git clone https://github.com/ALEX340001/Multi-LLMCodeExporter.git
cd Multi-LLMCodeExporter
dotnet build
