CLI‑ключи и фильтры

В этом разделе приведено полное описание всех параметров командной строки. Вы можете комбинировать ключи для точной настройки экспорта.

Основные ключи

Ключ Описание
<путь-к-проекту> Папка с проектом (первый аргумент без --). Можно передать путь к .csproj – будет использована его директория.
--help, -h, /? Показать справку.

Режимы экспорта

Ключ Описание
--mode=compact Только структура проекта и сигнатуры методов (~30% исходного размера).
--mode=balanced Оптимизация больших методов (сворачивание тел длиннее порога, по умолчанию 50 строк). Рекомендуется.
--mode=full Весь код без изменений (100% размера).

Фильтрация файлов

Ключ Описание
--exclude=шаблон Исключить файлы по шаблону (можно несколько). Примеры: *.Designer.cs, Forms, Tests.
--include=шаблон Включать только файлы по шаблону (можно несколько). Примеры: Domain, Services, Core.

Предустановленные наборы (preset'ы)

Ключ Описание
--backend-only Исключает UI‑файлы: *.Designer.cs, Forms, Views, UI, *.xaml.cs, *.razor.
--domain-services Включает только папки Domain, Services, Application, Core.
--compact-aggressive Включает --mode=compact, удаляет комментарии и пустые строки, порог сворачивания методов = 30.
--web-app Настраивает проект как веб‑приложение (JS, CSS, HTML), исключает node_modules, dist и т.д.

Формат вывода

Ключ Описание
--format=markdown Генерация отчёта в Markdown (по умолчанию).
--format=text Генерация в Plain Text.

Дополнительные настройки

Ключ Описание
--no-comments Удалить все комментарии (кроме XML‑документации ///).
--keep-empty-lines Сохранить пустые строки (по умолчанию удаляются).
--no-consolidate-usings Отключить консолидацию using-директив (только для C#).
--collapse-threshold N Задать порог строк метода для сворачивания (по умолчанию 50). Действует в режиме balanced.
--output=путь Папка для сохранения результата (по умолчанию Documents\LLMCodeExporter\Exports).

🧪 Примеры использования

# Интерактивный режим
LLMCodeExporter.exe

# Быстрый экспорт C# проекта в Balanced режиме
LLMCodeExporter.exe "C:\Projects\MyApp"

# Только бизнес-логика в Compact режиме
LLMCodeExporter.exe "C:\Projects\MyApp" --mode=compact --domain-services

# Исключить Designer и тесты, сохранить как Plain Text
LLMCodeExporter.exe "C:\Projects\MyApp" --exclude="*.Designer.cs" --exclude="Tests" --format=text

# Веб-приложение с максимальным сжатием
LLMCodeExporter.exe "C:\Projects\MyWebApp" --web-app --compact-aggressive

# Кастомный порог сворачивания и удаление комментариев
LLMCodeExporter.exe "C:\Projects\MyApp" --mode=balanced --collapse-threshold 30 --no-comments
