Быстрый старт

1. Общая информация

Multi‑LLMCodeExporter — утилита командной строки с интерактивным режимом для экспорта исходного кода в формат, удобный для загрузки в большие языковые модели (LLM). Она сканирует проект, фильтрует файлы, оптимизирует код (удаляет комментарии, сворачивает длинные методы, консолидирует using-директивы) и генерирует единый отчёт в Markdown или Plain Text с древовидной структурой, статистикой по токенам и навигационными ссылками.

Поддерживаются проекты на C# / .NET, Python, JavaScript/TypeScript, а также веб‑приложения (HTML, CSS, JS). Тип проекта определяется автоматически, но вы можете задать его вручную.

2. Способ 1. Работа через приложение (ярлык)

2.1 Windows

  1. Найдите папку, в которую вы распаковали скачанный архив программы.
  2. Запустите исполняемый файл LLMCodeExporter.CLI.exe двойным кликом.
  3. Просто перенесите (перетащите мышкой) в открывшееся окно программы свою рабочую папку, в которой вы ведёте разработку.

2.2 Linux

На Linux нельзя запустить программу двойным кликом, потому что это консольное приложение, которому нужен терминал для ввода/вывода. Запускайте её так:

  1. Откройте терминал.
  2. Перейдите в папку с распакованным архивом (например, cd /путь/к/папке) или просто перетащите исполняемый файл в окно терминала – путь подставится автоматически.
  3. Если файл ещё не имеет прав на выполнение, дайте их: chmod +x LLMCodeExporter.CLI.
  4. Запустите: ./LLMCodeExporter.CLI (или нажмите Enter после перетаскивания).
  5. Далее перетащите свою рабочую папку в открывшееся окно терминала (или введите путь вручную) – программа начнёт интерактивный опрос.

После запуска (вне зависимости от ОС) программа проведёт вас через пошаговый интерактивный опрос: выбор типа проекта, режима экспорта, фильтров, формата и дополнительных оптимизаций.

3. Способ 2. Запуск через консоль (CLI)

Если вам удобнее работать в терминале — например, для автоматизации, написания скриптов или интеграции в CI/CD — используйте интерфейс командной строки. В CLI-режиме вы можете гибко управлять поведением программы без интерактивного опроса, передавая все настройки через ключи. 

# Пример базового запуска (автоопределение типа, режим Balanced по умолчанию)
LLMCodeExporter.exe "C:\Projects\MyApp"   # Windows
./LLMCodeExporter.CLI "/home/user/Projects/MyApp"   # Linux

# Пример с явным указанием режима и фильтров
LLMCodeExporter.exe "C:\Projects\MyApp" --mode=compact --backend-only

4. Параметры командной строки (ключи)

Основные

Ключ Описание
<путь-к-проекту>Папка с проектом (первый аргумент без --). Можно передать путь к .csproj – будет использована его директория.
--help, -h, /?Показать справку.

Режимы экспорта

КлючОписание
--mode=compactТолько структура проекта и сигнатуры методов (~30% исходного размера).
--mode=balancedОптимизация больших методов (сворачивание тел длиннее порога, по умолчанию 50 строк). Рекомендуется.
--mode=fullВесь код без изменений (100% размера).

Фильтрация файлов

КлючОписание
--exclude=шаблонИсключить файлы по шаблону (можно указать несколько раз). Примеры: *.Designer.cs, Forms, Tests.
--include=шаблонВключать только файлы по шаблону (можно несколько). Примеры: Domain, Services, Core.

Предустановленные наборы (preset'ы)

КлючДействие
--backend-onlyИсключает UI‑файлы: *.Designer.cs, Forms, Views, UI, *.xaml.cs, *.razor.
--domain-servicesВключает только папки Domain, Services, Application, Core.
--compact-aggressiveВключает --mode=compact, удаляет комментарии и пустые строки, порог сворачивания методов = 30.
--web-appНастраивает проект как веб‑приложение (JS, CSS, HTML), исключает node_modules, dist и т.д.

Формат вывода

КлючОписание
--format=markdownГенерация отчёта в Markdown (по умолчанию).
--format=textГенерация в Plain Text.

Дополнительные настройки

КлючОписание
--no-commentsУдалить все комментарии (кроме XML‑документации ///).
--keep-empty-linesСохранить пустые строки (по умолчанию удаляются).
--no-consolidate-usingsОтключить консолидацию using-директив (только для C#).
--collapse-threshold NЗадать порог строк метода для сворачивания (по умолчанию 50). Действует в режиме balanced.
--output=путьПапка для сохранения результата (по умолчанию Documents\LLMCodeExporter\Exports).

5. Примеры использования

# 1. Интерактивный режим (без ключей)
LLMCodeExporter.exe   # Windows
./LLMCodeExporter.CLI # Linux (после chmod +x)

# 2. Быстрый экспорт C# проекта в Balanced режиме (по умолчанию)
LLMCodeExporter.exe "C:\Projects\MyApp"
./LLMCodeExporter.CLI "/home/user/Projects/MyApp"

# 3. Только бизнес-логика (Domain + Services) в Compact режиме
LLMCodeExporter.exe "C:\Projects\MyApp" --mode=compact --domain-services

# 4. Исключить Designer и тесты, сохранить как Plain Text
LLMCodeExporter.exe "C:\Projects\MyApp" --exclude="*.Designer.cs" --exclude="Tests" --format=text

# 5. Веб-приложение с максимальным сжатием
LLMCodeExporter.exe "C:\Projects\MyWebApp" --web-app --compact-aggressive

# 6. Кастомный порог сворачивания методов (30 строк) и удаление комментариев
LLMCodeExporter.exe "C:\Projects\MyApp" --mode=balanced --collapse-threshold 30 --no-comments
